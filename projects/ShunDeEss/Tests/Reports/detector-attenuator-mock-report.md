# SHUN DE-ESS detector and attenuator mock-signal report

Generated by `ShunDeEssTests --analysis-report`. Input is deterministic seeded broadband noise, a 500 Hz body tone, and a 7.8 kHz detail tone introduced after the detector has settled. All processing uses 48 kHz stereo blocks of 256 samples.

The detector Listen path was also measured with equal-level 500 Hz and 7.8 kHz tones; at the 7.8 kHz center setting, the in-band tone is 31.5 dB above the out-of-band tone.

| Mode | Detector GR (dB) | Broadband RMS reduction | 500 Hz body retained | 7.8 kHz detail retained |
|---|---:|---:|---:|---:|
| Wideband | 12.00 | 28.0% | 98.7% | 48.3% |
| Split-band | 12.00 | 19.0% | 100.0% | 35.4% |
| Smart | 12.00 | 19.1% | 98.6% | 71.9% |

Detector controls: 7.8 kHz center, Q 2.2, −48 dB threshold. Attenuator controls: 7.2 kHz center, Q 2.8, 12 dB maximum depth. The retained-detail column is a sine/cosine projection of the final 8192 samples; it shows how much of the isolated 7.8 kHz tone survives broadband attenuation. Smart is expected to retain more of that tone than Wideband while still reducing the broadband mock input.

The Smart spectrum plot is measured from the final 8192 samples of this same mock signal; the narrow 7.8 kHz tone is present in both input and output spectra. Source bins are in [smart-spectral-spectrum.csv](smart-spectral-spectrum.csv).
