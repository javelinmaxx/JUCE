# Ren Transformer tooltips

| Control | Tooltip |
| --- | --- |
| Core Drive | Increases saturation in YinYang's oversampled transformer stage. |
| DC Bias | Adds transformer asymmetry to increase even harmonics. |
| Core | Saves CPU when Off; adds YinYang's transformer coloration when On. |
| Output | Adjusts output gain before the transformer, also changing its input level. |
| Mix | Blends transformer coloration with the latency-aligned clean signal. |
| Bypass | Bypasses processing while preserving the plugin's latency. |
